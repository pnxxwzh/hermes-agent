# Hermes Agent v0.7.0 (v2026.4.2)

First release of the `mem-research` line for personal use.

Highlights:
- SparkGraph persistent memory storage backed by SQLite
- SparkGraph recall injection with visible CLI tracing
- Embedding-based semantic recall and vector backfill
- Memory lifecycle maintenance at Hermes-native review/flush times
- Conservative `RELATED_TO` graph edges for related knowledge points

Install (official-style):
```bash
curl -fsSL https://raw.githubusercontent.com/pnxxwzh/hermes-agent/v2026.4.2/scripts/install.sh | bash
```

After install:
- Hermes home defaults to `~/.hermes`
- Run `hermes` from any directory
